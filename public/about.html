서비스 소개

여기 뭐 생겨요?는 생활권 주변 공사 현장을 지도에서 확인하고, 해당 지점에 무엇이 생기는지 빠르게 파악할 수 있도록 만든 공공데이터 기반 서비스입니다.

왜 만들었나요?

길을 걷다 보면 공사 펜스만 있고 실제 사업명을 찾기 어렵습니다. 이 서비스는 위치 중심으로 주변 공사 정보를 조회해 불편을 줄이는 것을 목표로 합니다.

데이터 처리 원칙

  • 공공기관 Open API 원문을 정기적으로 동기화합니다.
  • 공사명, 주소, 좌표, 기간, 상태를 표준화해 제공합니다.
  • 원문 링크를 함께 제공해 직접 검증할 수 있게 합니다.
